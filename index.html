# Pixel Quest A browser-based RPG adventure game with progression, inventory, heroes, and boss battles. ## Features - Anonymous accounts - the first player becomes the owner - Persistent save system - 5 regions with enemy progression - Weapons and armor upgrades - Hero selection and owner custom hero creation - Shop system and coin economy ## How to Play 1. Open `index.html` in your browser 2. Create your account on the signup screen 3. Battle enemies to earn coins 4. Buy upgrades from the shop 5. Progress through regions 6. Create custom heroes if you are the owner ## Controls - WASD or Arrow Keys to move - Space to attack - Buttons in the UI for navigation ## Save Data Progress is saved in localStorage. Clear browser storage to reset. ## Files - `index.html` - main app shell - `arena.html` - battle arena - `app.js` - dashboard logic - `arena.js` - battle logic - `data.js` - game data and state - `style.css` - styling
